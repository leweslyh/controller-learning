## 一、稳定的三种等价说法

1. **极点说法**：闭环极点全部位于左半平面（连续域）。
2. **时域说法**：零输入响应随时间衰减到 0。
3. **频域说法**：开环 Nyquist 曲线不包围 $-1$ 点（等价于相位/增益裕度为正）。三者等价，但工程上各有用处：极点适合解析设计，裕度适合实验调试，时域适合看曲线。

## 二、按方法族查判据

| 方法族 | 判据 | 实验台上怎么看 |
| --- | --- | --- |
| PID 族 | Routh：$c+K_d>0$、$k+K_p>0$、$(c+K_d)(k+K_p)>mK_i$ | 增大 $K_i$ 直到曲线不再衰减，即越过第三条 |
| 频域补偿 | 相位裕度 $>0$、增益裕度 $>1$ | 加纯滞后直到振荡，即裕度被吃光 |
| 状态空间 / LQR | $(A,B)$ 可控、$Q\succeq0$、$R>0$ → Riccati 有正定解 | 增大 $Q/R$ 看响应变快、饱和变多 |
| 鲁棒 / H∞ | 闭环稳定 + 灵敏度峰值有界 | 加对象参数摄动，看指标退化幅度 |
| MPC | 预测模型准确 + QP 可行 | 加大纯滞后/限幅，看是否长期饱和 |
| 滑模 | 滑模面 Hurwitz（$c>0$）+ 切换增益 > 扰动上界 | 调小 $K$ 看是否到不了滑模面；调大看纹波 |
| 观测器 / ADRC | 观测器带宽 > 控制带宽；$b_0\approx1/m$ | 把 $\omega_o$ 调低，看估计滞后是否引发振荡 |
| 自适应 | 持续激励 + 增益有界 | 换成常值目标，看参数是否漂移 |
| 有限时间 / 约束 | 初始误差在约束内 + 控制量有界 | 把初始偏置调大，看是否越界 |
| 学习类 | 学习率小于稳定上界 | 学习率加倍，看是否发散 |

## 三、四个最常用的手算判据

**二阶**：$m s^2+cs+k=0$ 稳定当且仅当 $m,c,k$ 同号（正）。

**三阶（PID）**：$a_3s^3+a_2s^2+a_1s+a_0=0$ 稳定当且仅当 $a_2a_1>a_3a_0$（其余系数为正）。

**负刚度 P 控制**：$K_p>|k|$。导弹默认 $k=-2$，所以 $K_p\le2$ 必不稳定。

**负刚度 PI**：在 $K_p>|k|$ 基础上再加 $c(k+K_p)>mK_i$，积分增益被牢牢限制。

## 四、稳定 ≠ 好用

- **临界稳定**：极点落在虚轴上（如二阶积分器的 P 控制），幅值不衰减，任何扰动都会留下永久偏移。
- **稳定但极慢**：极点实部接近 0，$t_s$ 很长，教学上会被判「未收敛」。
- **稳定但抖振**：滑模增益过大时闭环稳定，但纹波 $\sigma_u$ 很大，工程上不可接受。因此实验台的评级同时看末段均值误差与尾段标准差：**均值到位但仍在振荡，不算 good**。

## 五、排查顺序（曲线异常时）

1. 先看执行器是否长期饱和——饱和会让所有线性判据失效；
2. 再看纯滞后/死区等非理想项是否过大；
3. 然后检查增益符号与量纲（角度对象是否误用了平移对象的增益）；
4. 最后才怀疑方法结构本身。
