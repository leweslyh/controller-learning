## 一、为什么不能只看位置曲线

位置贴住目标只是「结果对」，不代表过程好：可能控制力长期顶在限幅上、可能每 0.1 s 抖一次、可能能耗是别人的十倍。实验台的十张指标卡就是为了把「过程」摊开给你看。

## 二、十个指标的定义与判读

| 指标 | 定义 | 好的表现 | 常见误读 |
| --- | --- | --- | --- |
| 位置 $x$ / 误差 $e$ | 当前状态与目标之差 | 末段 $|e|$ 接近 0 | 用瞬时值判断收敛，忽略仍在振荡 |
| 速度 $v$ / $\omega$ | 一阶状态 | 到位后接近 0 | 只看位置、不看速度，误判"停住" |
| 超调 $\sigma\%$ | 越过目标的最大百分比 | ≤10%（无特殊要求时） | 把噪声尖峰当成超调 |
| 调节时间 $t_s$ | 误差进入 ±2% 带且不再越界 | 越小越快 | 显示「未收敛」时仍认为已到位 |
| RMSE | 全程误差的均方根 | 与 $t_s$ 一起看 | 单看 RMSE 会把"慢但不超调"判优 |
| 控制量 $u$ | 当前执行器指令 | 不长期贴限幅 | 只看峰值、不看持续时间 |
| 纹波 $\sigma_u$ | 控制量去均值后的标准差 | 越小越平滑 | 忽略它，导致抖振方法被误判为"准" |
| 切换频率 | 开关项每秒翻转次数 | 连续方法应接近 0 | 把高切换当成"响应快" |
| 稳态保持力 $u_h$ | 维持目标所需的常值力/力矩 | 与理论值一致 | 忽略它，误以为静差是控制器缺陷 |
| 能耗（累计/动态） | $\int u^2dt$ 与 $\int (u-u_h)^2dt$ | 同精度下更小 | 把"保持力"算进控制努力 |

## 三、四个组合判据

1. **快且稳**：$t_s$ 小、$\sigma\%$ 小、$\sigma_u$ 小——三者同时满足才算"好"。
2. **准**：末段 $|e|$ 小；若同时 $u$ 长期饱和，说明精度是靠顶限幅换来的，不可移植。
3. **省**：能耗低但精度不差；注意区分累计能耗与动态能耗——前者包含维持目标所需的保持力。
4. **鲁棒**：加扰动/噪声后指标退化可控；退化到"发散"说明稳定裕度不足。

## 四、一个对照练习

在「质量-弹簧-阻尼」上依次运行 P、PD、PID：

- P：$t_s$ 显示「未收敛」，$e$ 停在非零值（弹簧静差）；
- PD：$e$ 到 0、$\sigma\%$ 小，但阶跃刚开始时 $u$ 有明显尖峰；
- PID：$e$ 到 0、$t_s$ 更短，代价是 $\sigma\%$ 与 $\sigma_u$ 略增。把三次的指标卡并排抄下来，就能理解「快、准、稳、省」之间的折衷不是抽象口号。

## 五、常见陷阱

- **用 RMSE 排名**：长时间的小误差会掩盖短时间的大偏差，必须与超调、$t_s$ 联合看。
- **忽略量纲**：角度对象内部是 rad、界面显示 °，抄数时注意单位。
- **忽略冻结机制**：曲线在收敛后 2 s 自动定格，指标不再变化；要观察后续行为请先重置。
