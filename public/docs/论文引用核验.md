## 关联度（locator）与撤稿核查的边界

本平台的引用是「方法 → 其奠基/代表文献」的**出处标注**，不是论文正文中的论点支撑，
因此 `light-citation` 的 locator 三态（supports / partial / unsupported）在此不适用。
但「一法一文献」的对应关系仍需人工确认，本次已实证发现 **2 条作者/题名错配**（见 suspect 条目依据）。
对确定性可疑项，处置原则是**保留原始元数据 + 如实标注**，不自动替换为未经验证的文献。

**撤稿核查**：本批次未对 153 条 Crossref 命中记录逐条执行 `update-to[]` / Retraction Watch 核查，
按 `light-research-ethics` 的离线降级纪律，此处**不声称「已查无撤稿」**。
本平台为教学演示，引用仅作出处展示、不支撑投稿结论；若用于正式论文，须补跑
`light-research-ethics/scripts/check_retractions.py` 并交叉查 Retraction Watch。
